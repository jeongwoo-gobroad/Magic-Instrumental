## Separation invariants

`PIPELINE_VERSION=3`. Source identity is the full original file SHA-256. Processing signature includes exact model revisions/files/checksums/stem mapping, pinned engine, sample rate, chunk/batch/TTA/normalization and frame/variant recipes. Display labels and device are excluded. `variants.py` owns the fixed option IDs and `AudioVariant`; `pipeline.process()` retains its first four Result fields and legacy runner contract while adding selected variant, variants and original frame metadata.

The expensive model cache stores the full canonical original and all expected stems once; selected variant is excluded from its key. Canonical targets are `vocals`, `guitar`, `drums`, `bass`, `keys`, `piano` and `synth`; the last three are distinct, potentially overlapping estimates. Never label `other` as guitar or add outputs from independent models as if they formed an additive mix. Derived residual is canonical mixture minus target, in FLOAT with no per-stem normalization. Validate finite stereo 44.1 kHz and exact original sample frames before publishing. Accept only a bounded 0.1 s tail pad/trim and record that adjustment; never shift the start or score timeline.

Reuse validates input bytes plus every owned output's size/hash/audio grid without importing models, checking GPU or downloading weights.
