# 음원과 악보를 그대로 두고 업데이트하기

**2.4.6은 아래의 일반 업데이트 방법으로 적용합니다.** 기존 2.4.5 원본과 자동 따라가기 수정판 모두 업데이트할 수 있습니다. 자동 따라가기 수정도 포함되어 있으므로 별도 2.4.5 수정판 도구를 먼저 실행할 필요는 없습니다. 이전의 같은 버전 수정판에 관한 기록은 [2.4.5 수정판 적용 안내](DESKTOP_REPAIR.md)에 남아 있습니다.

인터넷이 연결된 상태에서 진행하세요. GUI의 업데이트 버튼은 프로그램을 자동으로 종료하며, update 파일을 직접 실행할 때는 먼저 프로그램을 닫으세요. **기존 프로그램 폴더를 삭제하거나 새 폴더로 옮길 필요가 없습니다.**

## Windows에서 실행하자마자 멈추거나 꺼지나요?

**Windows에서 ‘새 버전 확인 중’ 멈추거나 창이 꺼진다면:** 프로그램과 오류 창을 닫고 기존 폴더의 **`update.bat`**을 더블클릭해 v2.3.1 이상으로 업데이트한 뒤 **`start.bat`**으로 실행하세요. 프로그램 안의 업데이트 버튼을 누를 필요가 없습니다. 음원·악보·처리 결과를 삭제하거나 다시 설치할 필요도 없습니다. update 파일이 없다면 아래의 ‘업데이트 도구 받기’ 방법을 사용하세요.

## 프로그램 상단에 새 버전 안내가 보이나요?

v2.3.0부터 실행할 때 현재 버전과 새 버전을 자동으로 확인합니다. **변경 내용**을 살펴본 뒤 **종료하고 업데이트**를 누르면 업데이트 창을 열고 프로그램을 닫습니다. 창에 **업데이트 완료**가 나오면 평소의 `start` 파일로 다시 실행하세요. 자료와 설정은 유지합니다.

반주 생성·악보 분석·저장 중에는 완료될 때까지 기다려 주세요. 확인이 실패해도 프로그램은 계속 사용할 수 있고 **다시 확인**으로 재시도할 수 있습니다. 버전 확인은 공개 배포 정보만 조회하며 음원·악보를 전송하지 않습니다. 자동 설치는 하지 않습니다.

## 폴더에 update 파일이 있나요?

1. 평소 `start` 파일을 실행하던 폴더를 엽니다.
2. Mac은 **`update.command`**, Windows는 **`update.bat`**을 더블클릭합니다.
3. **업데이트 완료**가 나올 때까지 창을 닫지 마세요. 필요한 도구도 자동으로 확인합니다.
4. 같은 폴더의 **`start.command` / `start.bat`**으로 실행합니다.

이미 최신 버전이면 변경하지 않고 알려 줍니다. 관리자 권한이나 별도 Python 설치는 필요하지 않습니다.

## 구버전이라 update 파일이 없다면

1. [기존 사용자용 업데이트 도구 받기](https://github.com/jeongwoo-gobroad/Magic-Instrumental/releases/latest/download/Magic-Instrumental-Updater.zip)를 누릅니다.
2. 받은 ZIP을 **완전히 압축 해제**합니다. 기존 프로그램 위에 덮어쓰지 않아도 됩니다.
3. 압축을 푼 도구에서 Mac은 **`update.command`**, Windows는 **`update.bat`**을 더블클릭합니다.
4. 폴더 선택 창에서 **기존 프로그램 폴더**를 고릅니다. 평소 쓰던 `start` 파일과 `targets` 폴더가 들어 있는 위치입니다. `targets` 자체나 방금 받은 업데이트 도구 폴더를 고르지 마세요.
5. **업데이트 완료** 후 기존 폴더의 `start` 파일로 실행합니다. 이후 업데이트는 기존 폴더 안에 생긴 `update` 파일만 더블클릭하면 됩니다.

Mac에서 열기가 차단되면 내려받은 출처를 확인한 뒤 Finder의 우클릭 → 열기 또는 시스템 설정 → 개인정보 보호 및 보안의 안내를 따르세요. 처음 설치를 완료하지 않은 폴더는 먼저 그 폴더의 `install` 파일을 실행하세요.

## 무엇이 유지되나요?

- `targets`: 원본 음원
- `score_targets`: 원본 악보
- `processed`: 만든 반주, 분석 결과, 직접 보정한 시간표와 설정
- `models`: 이미 다운로드한 모델
- 저장한 `.magic` 파일, Windows의 가상환경 위치 설정, 기존 CPU/GPU 선택

프로그램 파일만 최신 정식 버전으로 교체합니다. 다운로드를 확인한 뒤 교체하며, 이전 프로그램 파일도 복구용으로 보관합니다. 새 버전에서 처리 방식이 바뀐 기능은 다시 분석해야 할 수 있지만, 기존 자료를 지우지는 않습니다. v2.1.1 이전 Windows의 GP 숫자 깨짐은 GP를 다시 열어 사전 분석하고 `.magic`을 새로 저장해야 반영됩니다.

## 중간에 실패하거나 창을 닫았다면

프로그램·설치 창을 모두 닫고 **같은 업데이트 도구를 다시 실행**하세요. 중단된 작업이 있으면 먼저 이전 프로그램을 복구합니다. 인터넷 문제로 실행 도구 복구까지 완료하지 못하면 연결을 확인한 뒤 다시 실행하세요. 완료 메시지가 나오기 전에는 `start`를 실행하지 마세요. 음원·악보·처리 결과 폴더를 지워서 해결할 필요는 없습니다.

개발용 Git 폴더는 이 도구로 업데이트하지 않습니다. 일반 사용자용 ZIP 설치 폴더를 선택하세요.
