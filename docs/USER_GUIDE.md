# 사용 안내

기존 사용자는 [자료를 유지하는 더블클릭 업데이트 안내](UPDATING.md)를 참고하세요.

[처음 설치하기](../README.md#처음-설치하기) · [변경 내역](../CHANGELOG.md)

작은 창에서는 메트로놈의 박자·속도와 음원 연동 설정을 두 줄에서 조작할 수 있습니다. 긴 곡명과 악보 안내는 창 너비에 맞춰 표시됩니다.

## 반주 준비와 재생

`targets/`에 직접 준비한 음원을 넣고 앱에서 새로고침합니다. 하위 폴더도 검색합니다. 곡을 선택해 **선택 곡 준비**를 누르면 파일 검증 → 모델 다운로드(필요 시) → 분리 → 결과 검증을 진행합니다. 작업 중 취소할 수 있으며, 완료된 캐시는 유지됩니다.

장치는 자동 선택하거나 CUDA / MPS / CPU를 명시할 수 있습니다. 명시한 GPU를 사용할 수 없으면 오류를 표시합니다. 메모리 절약은 작은 청크를 사용합니다. 기본 품질을 우선하려면 메모리가 부족할 때만 켜세요. 장치가 달라도 동일 파일·모델·처리 설정이면 캐시를 공유할 수 있습니다.

재생·일시정지·처음으로·탐색·반복·볼륨을 조작할 수 있습니다. 배속은 0.25~2배이고 음정 유지가 기본입니다. **현재 속도로 저장**은 항상 음정을 유지한 WAV/FLAC을 생성합니다. 원본 음원과 분리 캐시를 덮어쓰지 않으며, 다른 기존 파일을 교체할 때는 확인합니다.

캐시 폴더는 `processed/<음원 SHA-256>/<모델 및 처리 서명>/`입니다. 파일 이름만으로 재사용하지 않고 출력의 내용도 확인합니다. 원본 태그 수정이나 재인코딩은 내용 해시를 바꾸므로 다시 처리할 수 있습니다.

## 배속 시 피치 처리

첫 곡을 준비한 직후에도 **키 적용**으로 반주를 바꿀 수 있습니다. WAV·FLAC을 저장할 때 원본이 들어 있는 `targets`의 기존 파일을 선택하면 다른 이름을 요청합니다. Windows에서는 USB 드라이브 등 하드 링크를 지원하지 않는 위치에도 새 `.magic`을 저장할 수 있습니다.

앱 재생은 Qt `setPlaybackRate()`와 `setPitchCompensation(True)`를 사용합니다. 기본 FFmpeg 백엔드는 Signalsmith Stretch로 음정을 유지하며, 지원하지 않는 재생 장치에서는 **음정 유지 불가**를 표시합니다. 음정 유지를 끄면 가능한 백엔드에서 배속에 따라 음높이도 달라집니다.

**현재 속도로 저장**은 체크박스 상태와 관계없이 음정을 유지합니다. FFmpeg `atempo`를 사용하며, 0.25배속은 `atempo=0.5,atempo=0.5`, 0.75배속은 `atempo=0.75`입니다. 처리기 차이 때문에 앱 재생과 저장 파일의 질감이 다를 수 있습니다. 원본과 분리 캐시는 변하지 않습니다. [구현·출처 안내](../README.md#배속과-음정-유지)

## 드럼 카운트를 듣고 시작하기

1. 상단에서 원곡의 **BPM·박자**를 입력합니다. BPM은 4분음표 기준입니다. 예를 들어 6/8박자에서는 8분음표 여섯 번을 셉니다. 첫 박 위치를 보정했다면 그 기준도 사용합니다.
2. 재생 버튼 아래 **드럼 카운트**를 체크하고 **1~4마디**를 고릅니다. 기본은 꺼짐, 1마디입니다.
3. **재생**을 누르면 강박이 강조된 드럼 소리와 원형 박자 표시를 먼저 듣고 본 연주로 들어갑니다. 현재 배속은 카운트에도 적용됩니다. 120 BPM·4/4·1마디는 1배속 2초, 0.5배속 4초입니다.
4. 끄면 재생 버튼을 누를 때 바로 음악이 나옵니다. 체크 상태와 마디 수는 곡 변경·앱 재실행 후에도 유지됩니다.

**음원과 연동** 체크 여부와 관계없이 카운트를 사용할 수 있습니다. 카운트 음량은 상단 메트로놈 음량을 따르며, **무음**이나 0%에서는 원형 표시만 진행합니다. 카운트 중 일반 메트로놈 소리는 잠시 멈춥니다. 드럼 소리는 앱이 직접 합성하므로 추가 음원 다운로드가 필요하지 않습니다.

중간 위치에서 시작하면 원곡의 박 번호를 따라 셉니다. 박 사이의 시점에서 시작할 때에는 마지막 카운트 간격을 줄여 그 위치로 연결합니다. 원본 음원·재생 위치·첫 박 기준은 바꾸지 않습니다. 따라서 모든 중간 재생의 카운트가 ‘1박’부터 시작하지는 않습니다.

진행 중 **카운트 취소**를 누르거나 모드를 끄면 음악도 시작하지 않습니다. 탐색·곡 변경·BPM/박자/배속/첫 박 변경·분석 작업 시작·창 닫기도 대기 중인 재생을 취소합니다. 일시정지 후 다시 재생 버튼을 누르면 카운트를 반복합니다. 이미 재생 중인 음원의 탐색과 곡 전체 반복에는 카운트를 넣지 않습니다. 마디 구간 반복에서는 아래의 **매회 드럼 카운트**로 선택합니다.

소리 준비 실패나 심한 화면 멈춤으로 박을 놓치면 카운트를 취소하고 재생 버튼을 다시 누르도록 안내합니다. 느린 컴퓨터나 오디오 장치의 지연에 영향을 받을 수 있으므로 녹음용으로 샘플 단위의 정확한 시작을 보장하는 기능은 아닙니다.

## 악보 설치와 사전 분석

작은 창에서 악보의 위아래가 좁으면 **준비 도구 접기**를 누르세요. 페이지 이동과 확대는 그대로 쓸 수 있습니다. **준비 도구 펼치기**를 누르면 파일·파트 선택과 분석 버튼이 다시 나타납니다. 자동 스크롤을 쓰려면 원하는 크기로 맞춘 뒤 화면에 표시되는 재분석 안내를 따르세요.

PDF 표시는 앱에서 담당하며, 사용할 MusicXML 원본을 먼저 확인합니다. 원본이 없으면 **Audiveris**가 음표와 반복 기호를 인식합니다. 자동 모드에서 이 OMR 인식이 어려운 경우에만 PDF의 선과 픽셀에서 마디를 직접 찾고 입력한 BPM·박자로 시간을 계산합니다. 제공된 MusicXML의 오류를 이 추정 방식으로 대체하지 않습니다. **v1.3.0부터 기본 설치 파일이 Audiveris 5.11.0과 포함된 Java, 영어 OCR 데이터를 자동으로 준비·검증합니다.**

1. Mac은 `install.command`, Windows는 `install.bat`을 더블클릭합니다.
2. 공식 배포본 다운로드, 파일 검증, 영어가 적힌 합성 악보의 실제 인식 검사가 끝날 때까지 기다립니다. Java 설치나 Audiveris의 언어 메뉴 설정은 필요하지 않습니다.
3. **설치 완료**가 나오면 `start.command` 또는 `start.bat`으로 앱을 엽니다.
4. 다운로드나 인식 준비가 실패하면 같은 설치 파일을 다시 실행합니다. 검증된 다운로드는 재사용하고 손상된 설치는 복구합니다. 실패를 무시하고 설치 완료로 처리하지 않습니다.

인식 도구는 Mac `~/.vocal-separator-and-speed-adj/tools/`, Windows `%LOCALAPPDATA%\Magic-Instrumental\tools\` 아래의 버전별 폴더에 있습니다. Windows의 개인 가상환경 경로 설정과 별개입니다. 기존 수동 설치는 보존합니다. 설치 로그는 이 도구 폴더의 `install-omr.log`에 기록되며, 개인 경로가 있으므로 공개 전에 지우세요. 파일 해시·실행·영어 인식 확인은 설치 때 수행하고 평소 실행은 준비 여부만 확인합니다.

개발자가 별도 Audiveris를 사용하려면 `AUDIVERIS_EXECUTABLE`로 지정할 수 있고, 그 경우 `TESSDATA_PREFIX`도 직접 관리할 수 있습니다. 자동 설치본은 검증된 전용 영어 데이터를 항상 사용합니다. 추가 언어 자동 설치는 제공하지 않습니다. [공식 언어 안내](https://audiveris.github.io/audiveris/_pages/guides/main/languages/)

MusicXML 원본은 분석 창의 **MusicXML 선택**으로 지정할 수 있습니다. 선택란에 지정된 파일은 자동으로 찾는 원본보다 우선합니다. 다른 원본을 직접 고르거나, 선택란을 비워 자동 선택을 사용할 수 있습니다. PDF와 같은 이름의 `.musicxml`, `.mxl`, `.xml`, `.gp3`, `.gp4`, `.gp5`를 함께 두어도 자동으로 찾고 OMR을 생략합니다. 입력 우선순위는 **직접 선택 → 동명 파일 → 보정한 MusicXML → 내용이 검증된 이전 인식 → PDF의 실제 MusicXML 첨부 → Audiveris 인식**입니다. 캐시의 `recognition/reviewed.musicxml`에 새 보정본을 두었다면 이전 미보정 OMR보다 먼저 읽습니다. PDF의 워터마크·일반 메타데이터 XML은 음표와 마디를 담은 MusicXML로 취급하지 않습니다. 서로 다른 MusicXML이 여러 개 첨부되어 있으면 사용할 원본을 직접 선택해야 합니다.

**정렬**에서 **자동 · MusicXML 우선, 없으면 PDF 인식**, **음표와 음원을 자동 정렬 (추정)**, **일정 BPM으로 마디 시간 계산**을 고를 수 있습니다. 일정 BPM 방식도 MusicXML의 반복·코다 순서를 사용합니다. 일반 GP 사용은 **PDF / GP 열기**에서 바로 열고 파트 이름을 선택하세요. 고급 CLI에서는 `--musicxml`과 `--gp-track`으로 파일과 트랙을 지정할 수 있습니다. MusicXML에 페이지·줄 구분이나 마디 폭이 없어도 PDF의 실제 마디선을 이용하지만, 같은 악곡·원본 마디 순서·파트/보표 구성이어야 합니다.

**PDF만으로 마디 인식:** 자동 모드에서 사용할 MusicXML이 없고 OMR 인식이 어려운 경우 마디선을 직접 찾는 방식으로 전환합니다. 단일 보표, 4선/6선 타브, 오선·타브 병기, 피아노 두 단과 여러 악기의 총보에서 공통 마디 경계를 찾습니다. 시스템은 같은 시각에 연주되는 보표 묶음이며, 마디 수를 악기 수만큼 곱하지 않습니다. 파트 분리와 타브 운지 숫자·음높이 전사는 하지 않습니다. 시스템 묶음이나 마디선이 모호하면 자동 분석이 실패할 수 있습니다.

원곡의 4분음표 기준 BPM, 박자 분자/분모와 시작 지연을 입력하세요. 마디선·BPM 방식으로 자동 전환된 경우 기본 연주 순서는 인쇄 순서입니다. 반복·엔딩은 **연주 순서**에 원본 마디 순번으로 입력하고, 못갖춘마디·변박·템포 변화는 **시간표 · 보정**에서 시작 초와 끝 시간을 조정해야 합니다. 자동 대체 분석은 음원 특징으로 시간을 정렬하지 않습니다. 전환 안내가 표시되면 실제 반주와 마디 시간이 맞는지 확인하세요.

**이미지 악보:** PNG·JPG·JPEG는 직접 지원하지 않습니다. 사진·스캔 이미지를 넣은 PDF도 해상도·기울기·번짐에 따라 자동 인식이 어렵거나 실패할 수 있습니다.

**GP 원본:** **PDF / GP 열기**에서 GP3·GP4·GP5를 열면 별도 PDF 없이 선택한 파트를 표시합니다. 파트 이름을 고르고 사전 분석하세요. PyGuitarPro가 음높이·길이·박자·반복·지원되는 D.C./D.S./코다를 읽고 Verovio가 오선·타브를 그립니다. 타악기는 일정 BPM 방식으로 시간표를 만듭니다. GPX·GP6/7/8·이중 세뇨/코다는 지원하지 않습니다. 벤딩·셔플 등 세부 효과를 완전히 재현하지는 않습니다. 별도 PDF와 GP를 짝짓는 경우에는 같은 판본이어야 하며 마디 수가 다르면 중단합니다.

분석 상태에 현재 페이지·단계·경과 시간이 표시됩니다. 완료되지 않았다면 `processed/`의 해당 곡 악보 캐시 아래 `recognition/v2/work-…/omr.log`에 진단이 남습니다. 원본 파일명·경로가 포함되므로 로그를 그대로 공개하지 마세요. 불완전하게 읽힌 일반 마디는 박자표 길이를 유지하고 확인할 위치를 경고로 표시합니다. 명시된 못갖춘마디는 짧은 길이를 보존합니다. 이전 정상 시간표가 기록한 음원·PDF·인식 파일의 내용이 모두 일치하면 기존 인식 결과를 이어서 사용할 수 있습니다. 출처가 확인되지 않은 과거 OMR 파일은 자동 재사용하지 않습니다.

음원 `Practice Song.mp3`와 PDF `Practice Song.pdf`처럼 이름을 맞추세요. 대소문자와 한글 유니코드 표기 차이를 정규화해 찾습니다. 후보가 여러 개면 자동으로 고르지 않습니다. **PDF / GP 열기**로 다른 이름의 파일을 연결하거나 **다시 찾기**로 새 파일을 읽을 수 있습니다.

PDF 자체에서 용지 크기와 방향, 보표와 마디 경계를 먼저 확인합니다. 자동 대체 분석은 4·5·6선 보표를 사용합니다. A4/A3/A5/Letter/Legal과 사용자 규격, 페이지별 서로 다른 크기, 가로로 긴 악보, 짧은 마지막 줄을 처리합니다. 인쇄형 PDF는 벡터 선과 픽셀을 함께 읽고, 스캔은 픽셀 분석과 작은 기울기 보정을 사용합니다. 기존 XML 기반 분석에서는 PDF 텍스트의 D.C./D.S./Segno/To Coda/Coda/Fine과 명확한 반복 점 쌍으로 누락된 기호를 보충합니다. 반복·코다 구조가 불완전하거나 PDF와 인식 결과가 충돌하면 보정을 요청합니다. 자동 대체 분석도 마디에 연결된 이동 기호·반복 점이 있으면 직선 진행으로 완료하지 않습니다. 필요한 연주 순서를 직접 지정하거나 MusicXML을 보정하세요.

분석 뒤 악보 상태에 **실제 입력 출처**, 배치 분석 방식과 원본 마디 수가 표시됩니다. MusicXML을 읽고 PDF에서 위치를 찾은 경우 두 사실을 함께 표시합니다. 긴 안내는 상태 영역 안에서 스크롤해 끝까지 읽을 수 있으며, 마우스를 올리면 페이지 규격·줄 수·기울기 보정과 경고도 확인할 수 있습니다. **시간표 · 보정**에서도 경고를 확인하세요. 자동 대체 분석에서는 누락되거나 추가된 마디가 없는지 확인해야 합니다. PDF 마디선과 XML 인쇄 배치 모두 위치를 확정하지 못하면 스크롤 분석을 중단합니다. 이때 원본 파일과 기존에 연결된 정상 시간표를 보존합니다.

**배치 확인 필요 N줄**은 보표별 마디선 불일치, 제외된 경계 후보, 연결선 없이 추정한 보표 묶음 등이 있는 줄 수입니다. 정확도나 확률이 아닙니다. 상태 설명과 시간표의 경고를 보고 해당 줄을 원본과 비교하세요. 세로 마디선 증거가 없거나 경계가 지나치게 가까우면 시간표 생성을 중단합니다.

분석 순서는 다음과 같습니다.

1. 창 크기, 가운데 분할 비율, 악보 확대 배율을 먼저 정합니다. 한 페이지 / 너비 맞춤 / 최대 600%를 지원합니다.
2. **악보 사전 분석**을 누르고 사용할 MusicXML과 정렬 방식을 확인한 뒤 BPM·박자·시작 지연을 입력합니다. 기본 자동 모드는 원본을 먼저 읽으며, 원본이 없고 OMR 인식이 어려운 경우 PDF 마디선·BPM 추정을 사용합니다.
3. 반복·엔딩·D.C./D.S.·코다 연주 순서를 확인합니다. 자동 대체 분석에서는 필요한 반복을 **연주 순서**에 직접 지정합니다.
4. **시간표 · 보정**에서 마디 시작 초, 페이지, 전체 지연, 끝 시간을 확인·수정합니다. 행 더블클릭으로 해당 위치를 들을 수 있습니다.
5. **자동 넘김 · 스크롤**을 켜고 재생합니다. 원곡 시간으로 저장된 경로를 따라가므로 배속·탐색·반복·일시정지에 함께 반응합니다.

기존 XML/OMR 기반 분석은 일반적인 도돌이표, 1·2번 엔딩, D.C./D.S./Fine/Coda를 처리하지만 모든 복합 기호를 지원하지는 않습니다. 기호가 누락되면 Audiveris에서 수정해 MusicXML로 내보내거나, 분석 화면에서 연주할 **원본 마디 순번**의 목록/범위를 지정하세요. 자동 대체 분석의 순번은 인쇄 순서대로 1부터 시작하며, 인쇄된 마디 번호와 다를 수 있습니다.

기존 시간표가 있으면 **기존 마디 시간표 유지 · 화면 이동 경로만 분석**이 기본입니다. 수동 보정된 시간·페이지·전체 지연·검토 상태를 유지하면서 현재 확대 배율에 맞춰 스크롤만 계산합니다. 새 기호 해석을 적용하려면 이 체크를 해제해 전체 분석을 실행하세요. 이전 보정 파일은 보존되지만 새 자동 시간표를 다시 확인해야 합니다. 배율이나 패널 크기가 분석 때와 달라지면 **마디 표시와 페이지 넘김은 계속**하고 확대 스크롤만 멈춥니다. 같은 방법으로 화면 경로를 다시 계산하세요. 2.4.2부터 분석 완료 문구의 줄수 변화가 악보 영역의 크기를 바꾸지 않습니다. 재생 중에 새로운 기호 인식·줄 검출을 수행하지 않습니다.

**2.4.0 이후 진행이 달라진 악보 복구:** 악보를 다시 열면 같은 음원·PDF의 이전 보정 완료 시간표가 남아 있는지 확인합니다. 최근 결과가 미보정 자동 대체 결과이며 직접 입력한 연주 순서도 없다면, 내용이 일치하는 이전 보정본을 다시 연결합니다. 다른 음원·PDF의 시간표나 손상된 파일은 사용하지 않습니다. 복구할 보정본이 없으면 재분석 안내를 표시하고 전체 분석을 기본으로 선택합니다. 이미 보정했거나 연주 순서를 직접 지정한 결과는 자동으로 바꾸지 않습니다.

전체 분석에서도 내용이 검증된 기존 MusicXML과 이전의 음원 정렬/BPM 설정을 이어서 사용합니다. 이름이 다른 MusicXML을 선택했던 경우도 포함합니다. 인식 파일을 옮겼다면 **MusicXML 선택**으로 다시 지정하세요. 화면 경로만 재분석할 때에는 이전 분석과 내용이 정확히 일치하는 파일만 허용합니다. 파일의 내용이 바뀌었다면 전체 분석이 필요합니다. **시간 정렬 다시 계산**은 이전 보정 파일을 남기고 새 시간표를 만듭니다. PDF 분석 작업은 시간표와 요청한 스크롤 경로가 모두 성공한 뒤 새 결과로 연결합니다. 기존 `.magic` 파일은 자동 변경되지 않으므로 수정한 시간표로 다시 저장하세요.

마우스 휠, 스크롤바, 수동 페이지 이동은 자동 추종을 해제합니다. 다시 따라가려면 자동 넘김을 켜세요. 자동 대체 분석으로 만든 시간표에서는 같은 시스템 안의 세로 위치를 유지하고 다음 시스템에서 이동합니다. 총보 전체가 화면에 들어오도록 배율을 낮추세요. 4·5·6선 보표 배치 인식은 타브의 음높이 자동 인식을 뜻하지 않습니다. 흐리거나 심하게 기울어진 스캔, 손글씨, 장쉼표, 서로 다른 편집본과 모호한 보표 묶음은 실패하거나 수동 확인이 필요합니다. 마디선이 불확실할 때 임의로 등분하지 않습니다.

개발용 CLI에서도 XML 없이 실행할 수 있습니다.

```sh
python main.py score-analyze --audio recording.wav --pdf score.pdf --mode auto --bpm 120 --meter-beats 4 --meter-unit 4
```

`python`은 설치된 외부 가상환경의 실행 파일을 사용합니다. 분석은 원본 음원·PDF를 보존하고 별도 캐시에 저장합니다.

## 마디 단위 이동

분리된 음원이 준비되고 유효한 악보 시간표가 있어야 이전/건너뛰기 버튼이 활성화됩니다. N을 1~10,000으로 정하면 현재 방문 마디에서 N개 전후의 마디 시작으로 이동합니다. 도돌이표·코다를 펼친 실제 연주 순서와 회차를 사용합니다.

현재 마디 중간에서 1마디 이전을 누르면 **직전 마디 시작**으로 갑니다. 재생 중이면 재생을 계속하고 일시정지 상태면 정지 상태를 유지합니다. 음원 경계를 넘지 않으며, 전주에서는 첫 마디로, 악보 종료 후에는 마지막 마디로 접근할 수 있습니다. 악보 자동 추종이 꺼져 있어도 음원 이동은 가능합니다. 자동 추정 시간표의 오류는 마디 이동에도 반영되므로 먼저 시간표를 확인하세요.

## 시작·끝 마디 구간 반복

1. 음원을 준비하고 악보 사전 분석을 완료합니다. **시간표 · 보정**에서 실제 소리와 마디 시간이 맞는지 먼저 확인하세요.
2. 왼쪽 **시작 / 끝** 목록에서 구간을 고릅니다. 도돌이표로 같은 마디가 여러 번 나오면 **회차와 연주 순서**가 다릅니다. 예를 들어 `1마디 · 2회차`는 두 번째 연주의 1마디입니다. 재생 위치의 마디를 고르려면 옆의 **현재 마디**를 누릅니다.
3. **마디 구간 반복**을 켭니다. 일시정지한 채 시작 위치로 이동합니다. **재생**을 누르면 시작부터 **끝 마디 전체**를 연주하고 시작으로 돌아갑니다. 시작·끝을 같은 마디로 고르면 한 마디를 반복합니다.
4. **매회 드럼 카운트**를 켜면 첫 진입과 매 반복 전 카운트를 듣습니다. 위의 카운트 마디 수(1~4), 상단 원곡 BPM·박자·첫 박, 현재 배속, 메트로놈 음량·무음을 사용합니다. 일반 **드럼 카운트** 체크가 꺼져 있어도 매회 옵션만으로 동작합니다.

매회 옵션을 끄면 반복 사이에는 바로 시작합니다. 처음 재생하거나 직접 일시정지 후 재개할 때는 기존 **드럼 카운트** 설정을 따릅니다. 카운트 없이 시작하려면 두 옵션을 모두 끄세요. **카운트 취소**를 누르면 대기 중인 음악 재생도 취소합니다.

**곡 전체 반복**과 구간 반복은 동시에 켜지지 않습니다. 구간 반복 중 탐색 막대·마디 이동·시간표 이동은 구간 밖으로 나가지 않도록 제한되며, **처음으로**는 구간 시작으로 이동합니다. 구간을 벗어나려면 반복 체크를 끄세요. 음악 재생 중 반복을 끄면 현재 위치에서 계속 재생합니다.

시작·끝 마디를 변경하거나 마디 시간표/전체 지연을 바꾸면 반복을 해제하고 일시정지합니다. 확인 후 다시 켜세요. 곡 변경·분석/분리 작업도 반복과 대기 중 카운트를 해제합니다. 배율·화면 경로만 바꾸고 마디 시간이 동일하면 구간을 유지합니다. 선택은 음원 내용 해시와 시간표가 일치할 때만 복원하며 앱 시작 시 반복을 자동으로 켜지 않습니다.

악보 끝의 마지막 마디는 시간표의 끝 시간까지, 음원을 넘어가는 부분은 실제 곡 끝까지 사용합니다. 인식·정렬 오류는 반복 위치에도 반영되므로 시간표를 검토하세요. 입력 BPM이 일정하다는 전제이며, 반복 경계에는 타이머·오디오 장치 지연이 있을 수 있습니다. 샘플 단위의 무간격 반복 기능은 아닙니다.

## 메트로놈

**단독으로 쓰려면 ‘음원과 연동’을 해제한 뒤 **메트로놈 켜기**를 누르세요.** 음원 파일을 준비하지 않아도 됩니다. 상단 조작 줄 아래에 이 안내가 항상 표시됩니다.

현재 상태는 **꺼짐 / 단독 재생 중 / 음원 재생 대기 중 / 음원과 함께 재생 중**으로 표시합니다. 음원을 일시정지하면 연동된 메트로놈도 **음원 재생 대기 중**이 됩니다. 첫 박 전이나 드럼 카운트 중에는 해당 상태가 표시되고, **무음 / 음량 0%**도 함께 표시합니다.

상단의 **메트로놈 켜기 / 메트로놈 끄기** 버튼으로 조작합니다. 옆의 **음량**에서 클릭 크기를 0~100%로 조절합니다(기본 35%). 음원 볼륨과 독립적이며, 곡 변경·앱 재실행 후에도 유지됩니다. **무음**을 해제하면 선택한 음량으로 돌아옵니다. 0% 또는 무음에서도 박자 원형 표시는 계속 움직이며, 음량 변경은 박자 시계를 다시 시작하지 않습니다. 음원 없이도 단독 사용이 가능합니다. 박자 분자 1~12에 맞춰 원을 표시하며, 첫 박을 색과 높은 음으로 강조합니다. 분모는 2/4/8/16이고 BPM은 항상 4분음표 기준 20~400입니다. 예를 들어 6/8은 여섯 개의 8분음표 박을 표시합니다.

**음원과 연동**을 체크하면 입력칸은 원곡 BPM을 뜻합니다. 원곡 120 BPM × 0.75배속이면 90 BPM으로 움직이며 원곡 입력값은 바뀌지 않습니다. 체크하면 메트로놈이 대기 상태가 되고 음원을 재생할 때 함께 시작합니다. 음원이 정지·일시정지되면 클릭도 멈춥니다. 연동 중 클릭만 끄려면 **메트로놈 끄기**를 누르고, 다시 켜려면 **메트로놈 켜기**를 누르세요. 독립 모드는 음원 배속의 영향을 받지 않습니다.

원곡의 첫 강박 위치를 초로 입력하거나, 해당 위치에서 일시정지한 뒤 **지금 첫 박**을 누르세요. 전주·무음 때문에 어긋나는 박자를 맞출 수 있습니다. **무음**이면 원형 표시만 움직입니다. BPM·박자·첫 박은 곡별 내용 해시로 저장합니다. 재생 중 **지금 첫 박**을 누를 수도 있습니다.

탐색 막대·처음으로·이전/다음 마디·시간표 행 이동은 같은 동기화 경로를 사용합니다. 이동한 시점이 3박이면 세 번째 원을 표시하며 다음 박부터 맞춰 클릭합니다. 매번 1박으로 초기화하지 않습니다. 마디 첫 박에 정확히 이동하면 강박을 울립니다. 같은 마디 안에서 되돌리거나 곡 전체를 반복해도 첫 박 기준을 유지합니다. 일시정지 후 재개·배속 변경에서는 이미 울린 박을 다시 울리지 않고 다음 박을 이어갑니다. 버퍼 정체 중에는 클릭을 멈추며 밀린 클릭을 한꺼번에 재생하지 않습니다.

예: 원곡 120 BPM, 4/4, 첫 박 1.0초라면 2.25초는 3박 중간입니다. 이 위치로 이동하면 다음 클릭은 원곡 2.5초의 4박이고, 0.5배속에서는 그때까지 실제로 0.5초를 기다립니다. BPM 또는 첫 박 입력이 틀리면 지속적으로 어긋나므로 먼저 기준을 맞추세요.

템포 변화·루바토를 자동 추적하지 않으며, OS와 오디오 장치에 따른 클릭 지연이 있을 수 있습니다. 샘플 단위 동기화 장비를 대체하는 기능은 아닙니다.

## 문제 해결

| 현상 | 확인할 사항 |
|---|---|
| Mac에서 처음 여는 `.command` 파일의 개발자를 확인할 수 없다고 표시됨 | 공식 릴리스에서 받은 파일인지 확인하고 **시스템 설정 → 개인정보 보호 및 보안 → 보안 → 그래도 열기**에서 해당 파일을 허용하세요. [Apple 한국어 안내](https://support.apple.com/ko-kr/102445) |
| 설치가 중간에 멈춤 | 인터넷, 디스크 여유 공간, 백신 차단 로그를 확인하고 설치 파일을 재실행합니다. |
| 업데이트 후 설치 필요 안내 | 새 버전의 `install.command` / `install.bat`을 실행합니다. |
| Windows NVIDIA 오류 | 드라이버를 확인하거나 `install.bat -Cpu`로 다시 설치합니다. CUDA로 돌아가려면 `install.bat -Cuda`입니다. |
| 메모리 부족 | 메모리 절약을 켜고 다른 큰 앱을 닫습니다. 장치 명시 오류를 무시하지 마세요. |
| Windows 환경 경로 오류 | `venv-location.windows.txt`의 주석 외 한 줄, 절대 경로, 따옴표 유무, 프로젝트 밖 위치를 확인합니다. |
| PDF는 보이지만 기호 분석 불가 | 사전 분석이 PDF 마디선 방식으로 자동 전환되면 BPM·박자와 시간표를 확인합니다. 이 방식도 실패하면 인쇄 상태와 마디선이 선명한 원본인지 확인하세요. |
| 악보가 잘못된 곳으로 이동 | 반복 순서·시작 시간·전체 지연을 검토하고 필요하면 OMR을 보정합니다. |
| 확대 후 자동 스크롤 중지 | 현재 배율과 패널 크기에서 기존 시간표를 유지한 채 스크롤을 재분석합니다. |
| 마디 이동 비활성화 | 음원 준비 및 악보 시간표 로드를 먼저 완료합니다. |
| 마디 구간 반복 비활성화 | 음원과 악보 시간표를 준비하고, 끝 마디를 시작보다 같거나 뒤의 연주 순서로 고르세요. |
| 탐색이 구간 밖으로 나가지 않음 | **마디 구간 반복**을 끄면 곡 전체로 이동할 수 있습니다. |
| 음원이 목록에 없거나 열리지 않음 | 일반 음원 파일인지 확인합니다. DRM·스트리밍 캐시는 지원하지 않습니다. |

개발자 진단은 [CONTRIBUTING.md](../CONTRIBUTING.md)의 `doctor` 명령을 참고하세요. 진단 출력에는 개인 경로가 포함될 수 있으므로 공개 이슈에 올리기 전에 제거하세요. 음원·악보·분리 결과를 재현 자료로 올리는 대신 직접 만든 짧은 합성 신호나 이용 허가가 있는 자료를 사용하세요.

## 삭제와 저장 위치

앱을 종료한 뒤 프로젝트 폴더를 삭제하면 앱과 그 안의 원본·캐시도 함께 사라집니다. **직접 준비한 음원·악보와 필요한 내보내기 파일을 먼저 백업하세요.** 외부 환경을 지우려면 Mac의 `~/.vocal-separator-and-speed-adj/`, Windows의 개인 경로 설정에 지정한 환경 및 `%LOCALAPPDATA%\Magic-Instrumental\runtime`, `%LOCALAPPDATA%\Magic-Instrumental\tools`를 별도로 정리합니다. 다른 프로젝트와 공유하는 폴더 전체를 삭제하지 마세요.


## 반주 키와 태블릿 파일

**반주 키**에서 ±12반음을 정한 뒤 **키 적용**을 누릅니다. 준비하는 동안 일시정지하며, 완료 후 재생을 누르면 같은 위치에서 이어집니다. 원곡 키 버튼은 0반음을 적용합니다. 재생 속도와 별개로 음높이를 바꾸며, 원본 파일·악보의 음표·마디 시간은 바뀌지 않습니다. 원본과 다른 키를 듣고 있다면 악보를 읽을 때 고려하세요.

분석까지 끝났다면 **태블릿으로 가져가기 · .magic 저장**으로 내보냅니다. 현재 키의 반주와 PDF 또는 GP 원본, GP 전체 파트(또는 PDF)의 페이지와 마디 시간표를 담습니다. 재생 속도는 파일에 고정하지 않습니다. 모바일에서는 추가 키 ±12반음을 조절할 수 있고 처음 값은 0입니다. [iPad·Android 사용법](../web_player/README.md)

위쪽에서 밝은/어두운 화면을 고릅니다. **반주 만들기 설정**을 펼치면 모델·장치 선택이 나타납니다. 일반적인 사용은 기본 자동 설정으로 시작하세요.


## Session 모드

함께 연습할 때는 `.magic`을 준비한 뒤 **Session 모드 · 함께 연습하기**로 웹 합주 화면을 엽니다. 데스크톱 반주는 일시정지됩니다. 리더·멤버의 화면은 역할에 맞게 바뀌며, 멤버에게 재생 조작 버튼을 나열하지 않습니다. PC와 태블릿 모두 같은 합주 화면을 사용합니다. [코드·QR 초대와 파트 선택 순서](../web_player/README.md#session-모드로-함께-연습하기)
