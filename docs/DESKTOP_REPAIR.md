# 2.4.5 자동 따라가기 수정판 적용하기

악보를 직접 스크롤한 뒤 **자동 넘김 · 스크롤**을 다시 켰는데 현재 마디로 돌아오지 않는 문제를 수정합니다. 창 크기·배율을 바꾸거나 준비 도구를 접은 뒤에도 저장된 마디 위치를 이용해 따라갑니다.

**앱의 표시 버전은 2.4.5로 유지됩니다.** 이미 2.4.5를 쓰고 있다면 새 버전 알림이 나타나지 않으므로 아래 도구를 한 번 실행하세요. 기존 프로그램 폴더와 음원·악보를 옮길 필요가 없습니다.

## 기존 설치에 적용하기

1. [2.4.5 자동 따라가기 수정판 적용 도구 받기](https://github.com/jeongwoo-gobroad/Magic-Instrumental/releases/download/v2.4.5/Magic-Instrumental-2.4.5-follow-resume-1-Repair.zip)를 누르고 ZIP을 **완전히 압축 해제**합니다.
2. 반주 만들기·악보 분석·저장이 끝나면 Magic-Instrumental을 종료합니다. 인터넷에 연결된 상태에서 진행하세요.
3. 압축을 푼 도구에서 Mac은 **`repair.command`**, Windows는 **`repair.bat`**을 더블클릭합니다.
4. 폴더 선택 창에서 **평소 쓰던 프로그램 폴더**를 고릅니다. `start.command` 또는 `start.bat`과 `targets` 폴더가 들어 있는 위치입니다. `targets` 자체나 방금 압축을 푼 도구 폴더를 고르지 마세요.
5. 완료 안내가 나오면 기존 폴더의 **`start.command` / `start.bat`**으로 다시 실행합니다.

도구는 실행 중인 앱이 종료될 때까지 기다리고, 적용할 프로그램 파일을 확인한 뒤 백업하고 교체합니다. 적용 도중에는 창을 닫지 마세요. 이미 같은 수정판이 적용되어 있으면 변경하지 않고 알려 줍니다.

## 적용 후 사용하기

악보를 직접 움직인 뒤 **자동 넘김 · 스크롤**을 다시 켜세요. 마디 위치가 저장되어 있으면 현재 재생 위치로 즉시 돌아갑니다. 일시정지 상태에서는 화면만 맞추며, **마디 강조**를 꺼도 따라가기는 작동합니다.

분석 때와 같은 화면 크기·배율에서는 기존의 부드러운 이동 경로를 사용합니다. 화면 조건이 달라지면 저장된 마디 위치를 이용합니다. 새 화면에 맞는 부드러운 경로를 원하거나 예전 분석에 마디 위치가 없다는 안내가 나오면 **악보 사전 분석 → 기존 마디 시간표 유지 · 화면 이동 경로만 분석**을 선택하세요. 마디 위치가 없는 예전 분석도 페이지 넘김은 유지합니다.

이 수정판을 적용하는 것만으로 음표 인식이나 음원 정렬을 다시 할 필요는 없습니다. 데스크톱 따라가기 수정만을 위해 `.magic`을 다시 저장할 필요도 없습니다.

## 유지되는 자료와 적용 범위

원본 음원·악보, 만든 반주, 분석 결과와 보정 시간표, 모델, 개인 설정과 저장한 `.magic`을 유지합니다. 기존 폴더를 삭제하거나 자료를 새 설치 폴더로 복사하지 마세요.

| 현재 설치 상태 | 도구의 동작 |
|---|---|
| 기존 공식 2.4.5 | 프로그램 파일을 확인한 뒤 수정판 적용 |
| 이미 같은 수정판 적용됨 | 추가 변경 없이 완료 |
| 2.4.5보다 이전 버전 | 같은 도구로 전체 프로그램 업데이트 |
| 프로그램 코드를 직접 수정한 2.4.5 | 알 수 없는 코드 변경을 덮어쓰지 않고 중단 |
| 2.4.5보다 새 버전 | 이전 버전으로 내리지 않고 중단 |

프로그램이 열려 있다는 안내가 나오면 앱과 작업 창을 닫고 다시 실행하세요. 인터넷 연결 때문에 실패했다면 연결을 확인한 뒤 같은 도구를 다시 실행합니다. 코드가 수정되었거나 더 새 버전이라는 안내가 나오면 해당 설치를 강제로 덮어쓰지 마세요.

## 처음 설치하는 경우

[2.4.5 자동 따라가기 수정판 설치 파일](https://github.com/jeongwoo-gobroad/Magic-Instrumental/releases/download/v2.4.5/Magic-Instrumental-2.4.5-follow-resume-1.zip)을 받으면 수정이 이미 포함되어 있습니다. 압축을 완전히 푼 뒤 Mac은 `install.command`, Windows는 `install.bat`을 실행하고, 이후에는 `start` 파일을 사용하세요. 새로 설치한 수정판에는 위 적용 도구를 별도로 실행하지 않아도 됩니다.

일반 버전 업데이트 방법은 [자료를 유지하는 업데이트 안내](https://github.com/jeongwoo-gobroad/Magic-Instrumental/blob/main/docs/UPDATING.md)를 참고하세요.
