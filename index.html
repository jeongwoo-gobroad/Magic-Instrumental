    재생·일시정지·마디 이동은 리더만 조작합니다. 속도·키·반복 설정은 리더가 일시정지한 뒤 바꿉니다. 각자 파트·화면·음량·메트로놈 켜기는 자유롭게 고릅니다.

    공유 버튼을 누른 파일만 중계 서버로 전송합니다. 방 종료 시 삭제됩니다. 각자 파일을 열면 전송하지 않습니다. 합주 중에는 화면을 켜 두세요.

    처음 사용하시나요?

    컴퓨터의 Magic-Instrumental에서 반주와 악보 분석을 마친 뒤 ‘.magic 저장’을 누르세요. AirDrop·파일 전송으로 가져와 여기서 엽니다.

    컴퓨터에서 준비할 악보로는 Guitar Pro 원본(.gp3, .gp4, .gp5)을 권장합니다. 음표와 마디를 직접 읽고 연습할 파트를 고를 수 있습니다. 이 웹 재생기에서는 컴퓨터에서 저장한 .magic 파일을 여세요.

    iPad의 Safari·Chrome 또는 Android의 Chrome에서 이 웹주소를 열고 ‘.magic 파일 열기’를 누르세요. 파일 이름을 바꾸거나 압축을 풀 필요가 없습니다.

    홈 화면에서 앱처럼 열기
    iPad Safari: 공유 → 홈 화면에 추가(필요하면 ‘더 보기’) → ‘웹 앱으로 열기’가 보이면 켜기 → 추가.
    iPad Chrome: 공유 → 홈 화면에 추가 → 추가. 항목이 없으면 Safari에서 같은 주소를 여세요.
    Android Chrome: 메뉴(⋮) → 설치 및 바로가기 만들기 → 설치. 버전에 따라 ‘앱 설치’ 또는 ‘홈 화면에 추가’로 표시됩니다.

    홈 화면의 Magic Player를 온라인에서 한 번 열고 ‘오프라인 준비 완료’를 확인하세요. 그 뒤에는 기기에 저장한 .magic 파일을 인터넷 없이 열 수 있습니다. Session은 인터넷 연결이 필요합니다.

    새 버전은 앱 실행·화면 복귀·온라인 복귀 때 확인합니다. 아래 ‘업데이트 확인’으로 직접 확인할 수도 있습니다. 새 버전 안내가 나오면 연습과 Session을 마친 뒤 ‘업데이트 적용 · 다시 열기’를 누르세요. 현재 파일은 다시 선택해야 합니다. 업데이트 때문에 재생 중에 자동으로 화면을 다시 열지는 않습니다.

    연습 중에는 이 화면을 켜 두세요. 다른 앱으로 이동하면 일시정지됩니다. 음원과 악보는 정당한 권한을 가진 자료를 직접 준비해 주세요.
