시작 전에 꼭 확인해 주세요

지원하는 악보와 제약사항

권장 악보는 Guitar Pro 원본 파일(.gp3, .gp4, .gp5)입니다. 파일에 저장된 음표와 마디를 직접 읽고, 기타나 베이스 등 연습할 파트를 이름으로 고를 수 있습니다. GPX·GP6·GP7·GP8은 지원하지 않습니다.

PDF와 MusicXML — PDF 원본을 화면에 표시합니다. 같은 악보의 MusicXML(.musicxml, .xml, .mxl)이 있으면 사전 분석 창에서 함께 선택하세요. MusicXML은 음표와 연주 순서를 담은 악보 데이터이며, PDF에 첨부된 유효한 MusicXML도 우선 사용합니다. MusicXML이 없으면 PDF의 음표를 인식하고, 페이지에 인쇄된 반복·코다 글자와 기호를 함께 읽습니다.

음표 인식이 어려운 PDF — MusicXML이 없는 일부 악보는 마디선과 입력한 BPM·박자로 시간표를 계산할 수 있습니다. 오선과 타브가 함께 있는 악보나 여러 악기의 총보도 마디 배치를 찾을 수 있지만, 파트를 나누거나 타브 숫자를 음높이로 바꾸지는 않습니다. 총보는 같은 줄의 악기를 함께 보여 주므로 화면에 맞는 확대 배율을 정하세요.

반복·코다는 먼저 확인하세요. 연주 순서가 불완전하거나 서로 맞지 않으면 분석을 멈추고 보정을 요청합니다. 올바른 MusicXML이나 직접 확인한 연주 순서를 사용하세요. 마디선과 일정 BPM으로 계산한 시간은 못갖춘마디·변박·템포 변화에 맞춰 보정해야 합니다.

이미지 악보 — PNG·JPG·JPEG 파일은 직접 지원하지 않습니다. 사진·스캔 이미지를 넣은 PDF도 낮은 해상도, 기울기, 번짐이나 모호한 배치 때문에 인식이 어렵거나 실패할 수 있습니다.

  • 보컬 분리·PDF 기호 인식·음악과 마디 맞춤은 완벽하지 않을 수 있습니다. 사전 분석 후 실제 반주와 맞는지 확인하고 보정하세요.
  • 반주 키를 바꿔도 악보의 음표나 타브 숫자 자체는 바뀌지 않습니다.
  • 태블릿은 이미 준비한 .magic 파일을 재생합니다. 태블릿에서 음원 분리나 악보 분석을 하지는 않습니다.
  • DRM이 걸린 파일이나 스트리밍 앱 안의 다운로드는 지원하지 않습니다.
  • 실제 사용 가능 크기와 속도는 기기 메모리·성능에 따라 다릅니다. 모든 기기에서 같은 결과를 보장하지는 않습니다.

첫 곡 연습 순서

  1. 가수의 목소리와 악기 소리가 함께 들어 있는 일반 음원 파일(MP3·WAV 등)을 targets 폴더에 넣습니다.
  2. 컴퓨터에서 프로그램을 열고 새로고침을 누른 뒤 곡을 고릅니다. 선택한 곡의 반주 준비를 누르면 프로그램이 원곡에서 보컬을 분리해 연습용 반주를 만듭니다. 원본 음원은 그대로 보관됩니다.
  3. PDF / GP 열기로 악보를 열고, 확대 배율과 화면 너비를 정합니다.
  4. 악보 사전 분석을 누릅니다. PDF에 대응하는 MusicXML이 있으면 MusicXML 선택으로 지정하세요. 정렬은 기본 자동 설정을 사용하거나, 필요에 따라 음표와 음원을 자동 정렬 (추정) 또는 일정 BPM으로 마디 시간 계산을 고릅니다. 원곡 BPM·박자·시작 지연도 확인합니다.
  5. 시간표 · 보정에서 반주와 마디가 맞는지, 반복·코다에서 올바른 곳으로 이동하는지 확인합니다. 준비가 끝나면 자동 넘김 · 스크롤을 켭니다.
  6. 재생을 눌러 연습하고 필요하면 속도와 키를 조절하세요. 태블릿으로 가져가려면 .magic 저장을 누릅니다. 시간표를 보정한 뒤에는 다시 저장해야 태블릿에도 반영됩니다.

연습 중 창 크기·배율을 바꾸거나 준비 도구를 접어도 현재 마디 표시와 페이지 넘김은 계속됩니다. 페이지 안의 자동 스크롤을 다시 맞추려면 악보 사전 분석 → 기존 마디 시간표 유지 · 화면 이동 경로만 분석을 선택하세요.

Session 모드

같은 반주, 각자의 악보

PC·iPad·Android에서 리더가 초대 코드나 QR을 보여 주면 팀원이 참가합니다. 모두 준비한 뒤 리더가 재생·일시정지·마디 이동을 조작하고, 팀원은 자기 파트를 봅니다.

리더용 제어 화면과 멤버용 악보 화면으로 바뀝니다. 반주는 각 기기에서 재생하며, 서버는 연결과 시간 맞춤을 돕습니다.

Session 재생기 열기 ↗

Session은 인터넷과 켜진 화면이 필요합니다. 블루투스·출력 장치의 지연은 자동 보정하지 않습니다. 공유 버튼을 누른 파일만 서버로 전송됩니다.

연습에 활용할 기능

천천히, 원하는 키로

음정을 유지하며 배속을 조절하고, 반주 키를 반음 단위로 바꿉니다.

어려운 마디를 반복

시작·끝 마디를 정하고 반복합니다. 메트로놈과 시작 전 드럼 카운트도 사용할 수 있습니다.

내 파트를 크게

악보를 확대하고 재생 위치를 따라갑니다. 현재 마디의 초록색 강조는 PC·웹에서 기본으로 켜지며, 마디 강조로 끌 수 있습니다. GP 파일은 준비된 전체 파트 중에서 골라 볼 수 있습니다.

이미 사용하고 계신가요?

새 버전 안내부터 업데이트까지

PDF 분석이나 자동 넘김이 어긋났다면 업데이트 후 악보를 다시 열고 시간표를 확인하세요. 필요한 경우 사전 분석이나 화면 이동 경로 분석을 다시 실행하고, 태블릿용 .magic 파일도 새로 저장하세요.

Windows에서 ‘새 버전 확인 중’ 멈추거나 꺼지나요? 프로그램과 오류 창을 닫고, 기존 폴더의 update.bat을 더블클릭해 v2.3.1 이상으로 업데이트하세요. 완료 후 start.bat으로 실행합니다. 음원·악보·처리 결과를 삭제하거나 다시 설치할 필요가 없습니다.

프로그램을 열면 상단에 현재 버전과 새 버전 안내가 표시됩니다. 변경 내용 → 종료하고 업데이트로 진행하고, 완료 후 평소의 start 파일로 실행하세요. 인터넷 연결이 안 되어도 연습은 계속할 수 있습니다.

프로그램을 종료한 뒤 기존 폴더에서 Mac은 update.command, Windows는 update.bat을 더블클릭하세요. ‘업데이트 완료’가 나오면 평소 쓰던 start 파일로 실행합니다.

구버전이라 update 파일이 없다면 아래의 작은 업데이트 도구를 받으세요. 압축을 완전히 풀고 update 파일을 더블클릭한 뒤, 기존 start 파일과 targets가 들어 있는 프로그램 폴더를 선택합니다. 다음부터는 기존 폴더에 생긴 update 파일만 실행하면 됩니다.

기존 사용자용 업데이트 도구 ↓

음원·악보·만든 반주·보정 시간표·모델·설정·저장한 .magic 파일을 유지합니다. 기존 폴더를 삭제하거나 자료를 옮기지 마세요. 인터넷이 필요하며, 중간에 실패하면 같은 update 파일을 다시 실행하세요.
