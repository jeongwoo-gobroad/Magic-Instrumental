지원하는 악보와 제약사항

권장 악보는 Guitar Pro 원본 파일(.gp3, .gp4, .gp5)입니다. 파일에 저장된 음표와 마디를 직접 읽고, 기타나 베이스 등 연습할 파트를 이름으로 고를 수 있습니다. GPX·GP6·GP7·GP8은 지원하지 않습니다.

PDF와 MusicXML — PDF 원본을 화면에 표시합니다. 같은 악보의 MusicXML(.musicxml, .xml, .mxl)이 있으면 사전 분석 창에서 함께 선택하세요. MusicXML은 음표와 연주 순서를 담은 악보 데이터이며, PDF에 첨부된 유효한 MusicXML도 우선 사용합니다. MusicXML이 없으면 PDF의 음표를 인식하고, 페이지에 인쇄된 반복·코다 글자와 기호를 함께 읽습니다.

음표 인식이 어려운 PDF — MusicXML이 없는 일부 악보는 마디선과 입력한 BPM·박자로 시간표를 계산할 수 있습니다. 오선과 타브가 함께 있는 악보나 여러 악기의 총보도 마디 배치를 찾을 수 있지만, 파트를 나누거나 타브 숫자를 음높이로 바꾸지는 않습니다. 총보는 같은 줄의 악기를 함께 보여 주므로 화면에 맞는 확대 배율을 정하세요.

반복·코다는 먼저 확인하세요. 연주 순서가 불완전하거나 서로 맞지 않으면 분석을 멈추고 보정을 요청합니다. 올바른 MusicXML이나 직접 확인한 연주 순서를 사용하세요. 마디선과 일정 BPM으로 계산한 시간은 못갖춘마디·변박·템포 변화에 맞춰 보정해야 합니다.

이미지 악보 — PNG·JPG·JPEG 파일은 직접 지원하지 않습니다. 사진·스캔 이미지를 넣은 PDF도 낮은 해상도, 기울기, 번짐이나 모호한 배치 때문에 인식이 어렵거나 실패할 수 있습니다.

  • 보컬 분리·PDF 기호 인식·음악과 마디 맞춤은 완벽하지 않을 수 있습니다. 사전 분석 후 실제 반주와 맞는지 확인하고 보정하세요.
  • 반주 키를 바꿔도 악보의 음표나 타브 숫자 자체는 바뀌지 않습니다.
  • 태블릿은 이미 준비한 .magic 파일을 재생합니다. 태블릿에서 음원 분리나 악보 분석을 하지는 않습니다.
  • DRM이 걸린 파일이나 스트리밍 앱 안의 다운로드는 지원하지 않습니다.
  • 실제 사용 가능 크기와 속도는 기기 메모리·성능에 따라 다릅니다. 모든 기기에서 같은 결과를 보장하지는 않습니다.

한 파일에 여러 음원

필요한 항목을 체크해 함께 준비하고 한 .magic에 저장하세요. PC·웹의 재생 음원에서 바꾸면 같은 위치에서 멈추며, 재생을 눌러 이어갑니다.

저장된 음원 불러오기로 PC의 검증된 캐시를 다시 고르고, .magic에서는 파일에 담긴 항목을 선택하세요. PC·웹의 옵션 숨기기를 누르면 재생과 음원 선택을 남기고 악보를 넓게 볼 수 있습니다. 옵션 펼치기로 언제든 돌아옵니다.

키보드는 피아노·오르간 등을 포함한 건반 파트를 대상으로 합니다. 피아노와 신시사이저만 듣는 선택지도 따로 있습니다. 포함되는 소리가 겹칠 수 있으므로 원하는 음원을 하나씩 골라 비교하세요.

PC에서도 .magic 연습 파일 열기로 저장된 악보와 여러 음원을 바로 사용할 수 있습니다. 처음에 검증·준비한 결과는 다음에 캐시에서 불러옵니다. 분리 음질은 곡에 따라 달라집니다.

첫 곡 연습 순서

  1. 가수의 목소리와 악기 소리가 함께 들어 있는 일반 음원 파일(MP3·WAV 등)을 targets 폴더에 넣습니다.
  2. 컴퓨터에서 프로그램을 열고 새로고침을 누른 뒤 곡을 고릅니다. 준비할 음원에서 보컬·기타·드럼·베이스·키보드의 필요한 항목을 체크하고 체크한 음원 준비를 누릅니다. 여러 항목을 함께 준비할 수 있습니다. 해당 악기만 듣거나 그 악기를 뺀 반주를 만들 수 있습니다. 원본 음원은 그대로 보관됩니다.
  3. PDF / GP 열기로 악보를 열고, 확대 배율과 화면 너비를 정합니다.
  4. 악보 사전 분석을 누릅니다. PDF에 대응하는 MusicXML이 있으면 MusicXML 선택으로 지정하세요. 정렬은 기본 자동 설정을 사용하거나, 필요에 따라 음표와 음원을 자동 정렬 (추정) 또는 일정 BPM으로 마디 시간 계산을 고릅니다. 원곡 BPM·박자·시작 지연도 확인합니다.
  5. 시간표 · 보정에서 반주와 마디가 맞는지, 반복·코다에서 올바른 곳으로 이동하는지 확인합니다. 준비가 끝나면 자동 넘김 · 스크롤을 켭니다.
  6. 재생을 눌러 연습하고 필요하면 속도와 키를 조절하세요. 태블릿으로 가져가려면 .magic 저장을 누릅니다. 시간표를 보정한 뒤에는 다시 저장해야 태블릿에도 반영됩니다.

PC·태블릿으로 가져가기 · .magic 저장에서 저장할 음원을 여러 개 체크하고 처음 재생할 음원을 고르세요. 악보와 시간표는 함께 공유합니다. 반주 음질은 MP3 256 kbps · 권장이 기본입니다. MP3 128·192·320 kbps 또는 WAV · 무손실로 바꿀 수 있고, 저장할 때 확정한 선택을 기억합니다. MP3는 반주 용량을 줄이며 전체 파일의 감소 폭은 악보 크기에 따라 다릅니다. 기존 WAV 반주의 .magic도 계속 재생됩니다. 새 다중 음원 파일은 PC·웹 3.0.0 이상에서 엽니다. 위의 웹 업데이트 안내에 따라 재생기를 갱신한 뒤 여세요.

iPad에서는 Safari 또는 Chrome으로 웹 재생기를 먼저 연 뒤 .magic 파일 열기에서 파일을 선택하세요. 홈 화면 앱도 같은 순서로 사용합니다. 읽기가 끝나 곡 제목·시간·악보가 나타나면 재생을 누릅니다. 파일 열기가 멈췄거나 곡을 열어도 소리가 나지 않았다면 위의 웹 업데이트 순서로 갱신하고 맨 아래의 3.0.0 이상을 확인하세요. 2.4.6의 파일 읽기 개선과 2.4.7의 소리 재생 설정을 유지합니다. 소리 준비 오류가 나면 파일을 다시 열지 않고 재생 또는 합주 준비를 다시 누르세요. 기존 파일의 이름을 바꾸거나 다시 저장할 필요는 없습니다.

악보를 직접 움직였다면 PC의 자동 넘김 · 스크롤 또는 웹의 자동 따라가기를 다시 켜세요. 현재 마디가 바로 중앙으로 돌아오며, 반복·코다와 탐색도 해당 위치로 이동합니다. 저장된 마디 위치가 있으면 창 크기·배율·준비 도구를 바꾼 뒤에도 재분석 없이 따라갑니다. 예전 분석에 마디 위치가 없으면 악보 사전 분석 → 기존 마디 시간표 유지 · 화면 이동 경로만 분석을 선택하세요.

PC·iPad·Android에서 리더가 초대 코드나 QR을 보여 주면 팀원이 참가합니다. 모두 준비한 뒤 리더가 재생·일시정지·마디 이동을 조작하고, 팀원은 자기 악보 파트와 재생 음원을 고릅니다. 음원을 바꾸면 합주 준비를 다시 누릅니다.

내 파트를 크게

PDF·GP 페이지가 위아래로 이어지고 현재 마디가 악보 영역 중앙을 따라갑니다. 가까운 다음 줄·페이지로 부드럽게 이동합니다. 다음 부분이 보이는 범위는 배율·화면 높이·페이지 여백에 따라 달라지며, 배율을 낮추거나 악보 영역을 높여 더 넓게 볼 수 있습니다. 초록색 마디 강조는 PC·웹에서 기본으로 켜지며, 마디 강조로 끌 수 있습니다. GP 파일은 준비된 전체 파트 중에서 골라 볼 수 있습니다.

이미 사용하고 계신가요?

자료를 그대로 두고 3.0.1로

프로그램 상단의 변경 내용 → 종료하고 업데이트를 누르세요. 또는 앱을 종료하고 기존 폴더의 Mac update.command / Windows update.bat을 실행합니다. 업데이트 완료 후 같은 폴더의 start 파일로 다시 엽니다.

기존 2.4.x와 3.0.0 모두 같은 방법으로 업데이트할 수 있습니다. 3.0.1은 체크한 음원 함께 준비, 저장된 음원 불러오기와 PC·웹 옵션바 접기를 제공합니다. 이미 만든 반주·악보·.magic을 다시 만들 필요는 없습니다.

기존 사용자용 업데이트 도구 ↓

기존 폴더에 update 파일이 없으면 위 도구를 받아 완전히 압축 해제한 뒤, Mac은 update.command, Windows는 update.bat을 실행하세요. 평소 쓰던 start 파일과 targets가 있는 기존 프로그램 폴더를 고릅니다.

음원·악보·만든 반주·보정 시간표·모델·설정·저장한 .magic 파일을 유지합니다. 기존 폴더를 삭제하거나 자료를 옮기지 마세요. 업데이트에는 인터넷이 필요하며, 이미 최신 버전이면 변경하지 않습니다.
